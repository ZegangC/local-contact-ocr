# PRD：本地联系人资料整理与恢复

版本：公开展示v1，2026-11-04。根据已有原型整理，并新增可公开复验的离线方案；不是原型启动前的历史立项文档。

## 1. 用户、问题与目标

目标用户是在获得授权的环境中整理已有可见联系人资料的操作者。重复打开资料、区分昵称和备注、抄录数字及中断后重来，会带来漏项、混淆和重复劳动。当前未测量手工耗时，不承诺节省比例。

首要目标是可靠地提取可见字段、标明未知、保留进度并让操作者能复核。作品集版还需在不登录真实账号、不公开私人截图的条件下复现这些关键规则。

## 2. 本版范围与优先级

| 需求 | 优先级 | 本版交付 |
| --- | --- | --- |
| 合成界面与已知答案 | P0 | 昵称/备注/身份/电话面板及OCR读数由代码生成 |
| 三字段提取与缺失判定 | P0 | 昵称、备注、电话；区分没有、待核对、暂停 |
| 逐条保存与恢复 | P0 | SQLite提交、next_index、输入指纹、重复与冲突检查 |
| 可观察失败 | P0 | 两条保存后因边界缺失暂停，显式修正夹具后续跑 |
| 导出 | P0 | JSON/CSV/Excel，前导零保留，不生成公式 |
| 跨屏/末尾/停止验证 | P0 | 合成像素与假桌面对象测试；不操作真实Windows |
| 实际图像OCR | P1 | 可选本地模型评估，单独报告识别结果 |
| 真实通讯录全量运行、后台采集、云端同步 | 不在公开版 | 不提供实时输入适配器，不扩展原任务授权 |

## 3. 字段与数据对象

- 可见输出：微信名（昵称，非微信号）、备注姓名、电话号码，均保存为字符串。
- 内部身份：解析的标识，用于去重。公开示例全部为demo_开头的虚构身份。
- 状态：任务模式、输入夹具指纹、next_index、status、records、事件及暂停原因。
- 缺失：有完整空字段证据才为“没有”；区域不全、两次读数冲突、模糊或低置信度为待核对/暂停。
- 数字：保留观察结果中的前导零、异常长度和多个值，不据号码形状证明准确性或归属。

## 4. 工作流与状态

生成输入 → 检查上下文 → 分别解析资料与备注 → 比较读数 → 确认身份 → 逐条提交 → 推进断点 → 导出。

| 状态 | 触发 | 退出/后续 |
| --- | --- | --- |
| running | 新任务或已校验恢复 | 成功逐条推进，错误进入暂停 |
| paused | 输入不全、冲突、上下文变化或停止 | 复核并提供修正后的观察，保留旧数据 |
| limit_reached_not_full_address_book | 达本批上限 | 不能说已全量完成 |
| synthetic_fixture_complete_not_live_address_book | 已处理本夹具所有观察 | 只表示合成范围结束 |

原导航规则另区分advanced、navigation_stalled_or_end_needs_check与visible_list_end_reached_scope_from_selected_start。可见末尾不证明起点之前无遗漏。

## 5. 异常与恢复

同身份同内容不重复新增；同身份不同内容暂停。恢复必须使用相同夹具指纹，不能把另一批资料接到旧任务。缺签名类身份确认不猜测；下划线候选规范化需第二次读数一致。

导出被占用等OSError记录export_error，先前数据库提交和状态仍保留；再次恢复可重新导出。公开演示单进程运行，未提供多进程任务锁，不能据此宣称具备原型所有运行保护。

## 6. 可测试验收

| 编号 | 条件 | 预期 |
| --- | --- | --- |
| AC01 | 只有空OCR或缺下边界 | 不写“没有” |
| AC02 | 原色/反色或身份确认不一致 | 暂停，不提交不确定联系人 |
| AC03 | 同备注不同身份 | 两条都保留 |
| AC04 | 同身份不同内容 | 旧数据不覆盖，任务暂停 |
| AC05 | 两条后暂停并重开任务 | 原两条保留，续跑不重复累计 |
| AC06 | 停止、焦点/尺寸/账号信号变化 | 在保存前暂停；信号在公开版中为注入值 |
| AC07 | 下一页变化或不能推进 | 根据合成像素判断，停滞不假报全量完成 |
| AC08 | 导出数字/公式形状文本 | 前导零不丢，无Excel公式；CSV转义 |
| AC09 | 文件导出失败 | 数据库和状态保留，允许后续重导 |
| AC10 | 真实图片OCR评估 | 与夹具规则测试分开报告，保留失败和未知 |

## 7. 指标与发布门槛

规则通过数、字段精确匹配数/明确分母、待核对数、误判为空数、已保存记录一致性、恢复后重复数分别报告。没有将“输出了结果”当作“全部识别正确”。发布需完成合成数据检查、离线测试、结果核对和文件清单复核，不迁入真实联系人资料。
