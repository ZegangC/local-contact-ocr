# 架构与原项目对应

## 公开版执行路径

src/fixtures.py生成虚构面板、像素列表和OCR文本 → src/core.py解析字段 → src/replay.py检查上下文与一致性 → SQLite逐条提交 → 状态和三列文件 → tools/build_demo_assets.py输出示例报告及动画。

可选tools/evaluate_ocr.py另走“生成面板 → 真实本地模型 → 原色/反色结果 → 字段评价”，不与默认的OCR文本重放混用。

## 原规则抽取

core.py从原本地原型整理Store、profile_fields、edit_fields、selected_row、avatar_rows、advance等规则；phone_field与extract_candidates来自其字段/OCR辅助模块。移除了原项目绝对路径、桌面输入接口、真实截图依赖和本机环境设置。没有读取或迁入私人数据。

公开版新增ReplayRunner对应的run_replay、虚构输入指纹、双读数一致性与低置信度拒识、更严格的不确定字段暂停。原型可能保存待核对字段，公开演示采用“先暂停、后显式修正”的展示策略；不把新策略说成原型全部行为。

## 关键边界

- 不包含原Windows Desktop输入适配器；焦点、尺寸与账号状态在重放中通过布尔信号注入，不能验证实际系统拦截能力。
- 图片导航代码读合成像素，不使用联系人名称做列表定位；但仍与846×832校准布局相关，不是任意界面理解。
- 同身份/同内容去重，身份来自观察；不具备真实账号权威认证。
- SQLite逐条提交，文件导出是快照；导出失败不回滚已提交数据。状态文件与数据库不是单一事务，极端崩溃恢复仍有进一步工程空间。
- 默认新任务拒绝覆盖已有任务；公开版是单进程工具，未提供多进程文件锁。
- Excel使用字符串，CSV对公式形状文本加前缀。导出模块为继承的最小OpenXML实现，未对所有Excel客户端做兼容验收。

代码由AI辅助整理与测试。作者需要能够解释和复核这些选择；公开文件与测试数量不直接证明个人独立工程熟练度。
