# 公开边界与数据处理

本仓库只包含代码生成的虚构名字、身份、数字和界面。0开头的数字是测试字符串，不代表真实号码、号码归属或可联系对象。

未迁入：原微信截图、昵称/备注/微信号、电话号码、原始OCR结果、联系人表、运行SQLite、真实任务状态及事件、账号头像、错误日志、缓存和虚拟环境。

公开生成目录为artifacts；私人运行或新试验应留在被忽略的outputs/runs/results目录。忽略规则不是隐私审计替代，发布使用明确文件清单。不要将真实账号截图覆盖到合成文件名后直接推送。

默认重放无网络、无微信操作、无消息发送。可选OCR执行本地模型，首次依赖安装需要网络。公开演示不提供对任何账号的实时操作授权；实际资料处理应限于已获授权、明确用途的范围，控制保存和分享。

本版没有自动清理历史输出、访问控制或加密存储，不能描述为企业隐私合规认证。真实业务资料若另行处理，需要相应的访问、保留和删除安排。
